# The raffle slip on the clipboard

Each table that paid gets a ticket. The rule on the clipboard is short: take the table number and multiply it by nine. Table 1 is ticket 9. Table 2 is ticket 18. The same rule is the whole slip.

The copy I actually have only lists tables 1, 2, and 4. Any other table, including zero, was not written down. Raise ValueError and say "that table is not on the slip".
